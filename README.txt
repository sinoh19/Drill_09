# Drill 09 - 소년 이동과 애니메이션

## AI 기획 요구사항 문서

### 1. 과제 목표

Python과 pico2d를 이용해 방향키로 소년을 움직이는 프로그램을 만든다.
키보드 입력 처리와 스프라이트 애니메이션 구현 방법을 익힌다.

### 2. 개발 환경 및 파일

- 개발 언어: Python
- 사용 라이브러리: pico2d
- 실행 파일: `Drill_09/Drill_09.py`
- 배경 이미지: `TUK_GROUND.png`
- 캐릭터 이미지: `animation_sheet.png`
- 화면 크기: 800 × 600

### 3. 기능 요구사항

1. 프로그램을 실행하면 배경과 소년을 화면에 표시한다.
2. 상하좌우 방향키를 누르면 소년이 해당 방향으로 이동한다.
3. 이동하지 않을 때는 idle 애니메이션을 반복한다.
4. 이동할 때는 왼쪽 또는 오른쪽 이동 애니메이션을 재생한다.
5. 위·아래로 이동할 때는 마지막으로 바라보던 좌우 방향을 유지한다.
6. 소년이 화면 경계에 도착하면 화면 밖으로 나가지 않도록 한다.
7. ESC 키를 누르거나 창을 닫으면 프로그램을 종료한다.

### 4. AI 활용 계획

AI에게 위 요구사항과 수업 예제 코드를 전달하여 구현 도움을 받는다.
작성된 코드를 읽고 직접 실행하면서 이동, 애니메이션, 화면 경계 처리를 확인한다.
오류가 발생하면 오류 메시지를 전달하고 수정 내용을 확인한다.

### 5. 동작 확인 항목

- 방향키를 누르거나 떼었을 때 이동과 정지가 정상적으로 되는가?
- 정지 상태와 이동 상태에 맞는 애니메이션이 나오는가?
- 위·아래 이동 시 바라보는 방향이 유지되는가?
- 화면의 네 방향 경계에서 소년이 화면 밖으로 나가지 않는가?
- 배경 이미지가 표시되고 ESC 키로 종료되는가?
